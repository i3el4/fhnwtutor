Business Analytics Tutor in RStudio

Statt Fragen in einem Chatfenster zu stellen und Code hin und her zu kopieren, arbeiten Sie direkt im Editor: Sie markieren eine Stelle in Ihrem Skript, drücken ein Tastenkürzel und wählen mit einem Knopf, was passieren soll. Das Ergebnis erscheint an Ort und Stelle. Das Add-in stellt dafür fünf Assistenten bereit, die auf die Arbeitsweise in diesem Modul zugeschnitten sind. Paketname in R: fhnwtutor.

Installation in einer Zeile
In der RStudio-Console eingeben: 
install.packages("fhnwtutor", repos = c("https://i3el4.r-universe.dev", getOption("repos")))
Anschliessend brauchen Sie noch einen eigenen, kostenlosen API-Key. Die vollständige Anleitung dauert etwa 15 Minuten. Ein GitHub-Konto ist nicht nötig.
Was Sie dafür brauchen
R ab Version 4.3, RStudio Desktop und einen eigenen kostenlosen Gemini-API-Key von Google. Jede Person richtet einen eigenen Key ein; Keys werden nicht weitergegeben.

Datenschutz: Der kostenlose Gemini-Zugang (Free Tier) übermittelt den markierten Text an Google. Google kann diese Inhalte zur Produktverbesserung verwenden. Schicken Sie deshalb keine vertraulichen oder personenbezogenen Daten durch das Add-in — keine Matrikelnummern, keine Klausurdaten, keine Datensätze mit Personenbezug. Für Übungsdaten und eigenen Code ohne Personenbezug ist es unproblematisch.

Welche Assistenten gibt es?

⚙
Umsetzen

Markieren Sie eine Frage in normalem Deutsch — etwa wie Sie eine Excel-Datei einlesen — und der Assistent ersetzt sie durch R-Code. Pfade, die Sie nicht angegeben haben, bleiben Platzhalter.

🔍
Erklären

Erklärt eine Fehlermeldung oder einen Codeblock ohne Informatik-Jargon: was passiert und was das praktisch bedeutet. Die Erklärung erscheint als Kommentar unter der markierten Stelle. Der Originalcode bleibt stehen.

✍
Kommentieren

Ergänzt vorhandenen Code um deutsche Kommentare. Der Fokus liegt auf dem Was und Warum eines Schritts, nicht auf der Syntax. Der Code selbst wird nicht umgeschrieben.

🧭
Bereinigen

Überführt Base-R-Code in lesbaren tidyverse-Stil mit der Pipe |>. Nützlich, wenn Sie Code aus dem Internet übernommen haben und ihn an die Schreibweise aus dem Unterricht angleichen wollen.

🔗
Erweitern

Schlägt zu markiertem Code einen nächsten plausiblen Analyseschritt vor. Der Vorschlag erscheint unter der Auswahl; der markierte Code bleibt stehen.
