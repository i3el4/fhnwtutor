# fhnwtutor

Persönliches RStudio-Add-in für Business-Analytics-Lehrveranstaltungen an der FHNW.

Basiert auf [chores](https://simonpcouch.github.io/chores/) + [ellmer](https://ellmer.tidyverse.org).
Modell: Google Gemini Free Tier (`GEMINI_API_KEY` in `~/.Renviron`).

## Stufe A (aktuell)

Eigene Prompts als Markdown-Dateien in `prompts/`, registriert über `chores`.
Konfiguration liegt in `~/.Rprofile`.

## Stufe B (noch nicht)

Überführung in ein echtes R-Paket nach dem Muster von
[palpable](https://github.com/simonpcouch/palpable).
